# Asset sources and usage

## Challenge-provided assets

The visual and audio assets in `public/assets/` and the source vector files in
`assets-src/vector/` were provided as the visual basis for the Jungle Gaming
Game Developer Challenge.

- Challenge repository: https://github.com/junglegaming/game-developer-challenge
- Referenced asset directory: https://github.com/junglegaming/game-developer-challenge/tree/main/assets
- Challenge README instruction: use the supplied assets as the visual basis and
  include their sources and licenses with the submission.

## Usage scope

For this project, treat these assets as restricted to this technical challenge
submission. Their presence in the challenge repository does not establish that
they are public domain or grant permission to use them in unrelated projects,
public portfolio materials, or commercial games.

No separate asset license file or individual asset-license manifest was
identified in this project. This document records the challenge source and the
usage restriction applied to this submission; it does not claim an independently
verified, general-purpose license. Obtain explicit permission from the relevant
rights holder before using these assets outside the challenge.
